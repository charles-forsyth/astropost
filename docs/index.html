AstroPost: Rich-Text Terminal Gmail Client & AI Executive Summarizer

A comprehensive Python CLI for Gmail reading, search, executive AI summarization, interactive inbox triage, Markdown-to-HTML composition, and draft management directly from your terminal.

uv tool install --python 3.12 git+https://github.com/charles-forsyth/astropost.git
View Repository Explore Terminal Output

Key Capabilities

Designed and tuned for modern terminal workflows and automated pipelines.

✨

Inbox Listing & Search

View unread or recent messages and run full Gmail search queries with Rich tables or JSON output.

✨

AI Executive Summarization

Generate concise executive summaries of unread emails or conversation threads using Google Gemini.

✨

Interactive Inbox Scanner

Step through unread emails in the terminal with one-key triage: read body, summarize, mark read, archive, or delete.

✨

Markdown-to-HTML Sending

Write emails in Markdown with your favourite editor, automatically compiling to responsive HTML with file attachments.

Terminal Showcase

Real, unmodified terminal outputs captured directly from the CLI engine.

astropost --help

Usage Examples

Quick command recipes for terminal operations.

List Unread Emails

List latest unread messages with Rich formatting:

astropost list --unread --max-results 10

Search Inbox

Run rich Gmail search query with filters:

astropost search "from:support subject:incident" --max-results 5

AI Executive Summary

Summarize unread emails with Gemini:

astropost summarize

Interactive Triage Scanner

Step through messages with single keystroke actions:

astropost scan
